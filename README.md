# 🍕 Pizza Sales Analysis Using posterSQL

## 📌 Project Overview

The Pizza Sales Analysis project is a data analytics project developed using SQL and PostgreSQL to analyze pizza sales data and generate meaningful business insights.

The main objective of this project is to analyze overall sales performance, revenue trends, customer ordering behavior, pizza category performance, and top and bottom-performing pizza products.

SQL queries are used to calculate key performance indicators (KPIs), identify sales trends, and understand business performance through data-driven analysis.

## 🎯 Project Objectives

- Analyze overall pizza sales performance.
- Calculate important business KPIs.
- Understand monthly and daily sales trends.
- Analyze revenue contribution by pizza category.
- Identify sales distribution by pizza size.
- Find the top and bottom-performing pizzas.
- Analyze pizza sales based on revenue, orders, and quantity sold.
- Generate meaningful insights to support business decisions.

## 📂 Dataset Description

The project uses a Pizza Sales Dataset containing order-level pizza sales information.

### Important Columns

- `ORDER_ID` – Unique customer order identifier.
- `ORDER_DATE` – Date of the pizza order.
- `PIZZA_NAME` – Name of the pizza.
- `PIZZA_CATEGORY` – Category of the pizza.
- `PIZZA_SIZE` – Size of the pizza.
- `QUANTITY` – Number of pizzas sold.
- `TOTAL_PRICE` – Total sales amount.

## 📊 Key Performance Indicators (KPIs)

The following KPIs were calculated using SQL queries:

### 1. Total Revenue
Calculates the total revenue generated from pizza sales using SUM().

### 2. Total Orders
Calculates the total number of unique orders using COUNT(DISTINCT ORDER_ID).

### 3. Average Order Value (AOV)
Calculates the average revenue generated per order.

Formula:
Total Revenue / Total Orders

### 4. Total Pizzas Sold
Calculates the total quantity of pizzas sold using SUM(QUANTITY).

### 5. Average Pizzas Per Order
Calculates the average number of pizzas sold per order.

Formula:
Total Pizzas Sold / Total Orders
